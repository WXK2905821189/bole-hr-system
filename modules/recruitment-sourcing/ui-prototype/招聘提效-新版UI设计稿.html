「识才信号台」
从 自动索简历 到 触达成交 的精密运营台

新版 UI 以「识才信号台」为概念种子：把招聘提效的每一步抽象为一道「信号」——寻源扫描、信号入库、触达脉冲、成交复盘。系统仍是每日高频使用的运营工具，因此本设计在精密运营台 (precision operations) 基础上注入克制的品牌叙事，用「电感靛蓝」承载主操作、「伯乐琥珀金」标记关键状态，层次分明、扫读即懂。

设计方向与概念

Design Direction · 伯乐=识才
概念种子精密运营台
◎
信号扫描 · 持续寻源

以「雷达 + 信号灯」隐喻贯穿：检索命中、解析入库、匹配打分均呈现为可读的管道与信号，让采集过程「可视化而非黑盒」。

⇶
触达脉冲 · 分级推进

打招呼、跟进、唤醒等触达动作抽象为「脉冲节拍」，话术库与跟进引擎以节奏 + 状态呈现，契合每日高频操作

◎
伯乐金 · 状态唯一主色

靛蓝为主操作、琥珀金只用于「值得注意」（待招呼/已读未回/风控），其余状态以克制中性色承载，避免彩虹仪表盘

◈品牌叙事落到视觉：「伯乐」= 一眼识才。据此，候选人行内用「伯乐指数 / 匹配分」做主视觉信号，触达状态用信号灯式色点，采集调度用雷达扫描动画——每个高频页面都有一处可记忆的「识别时刻」，而非千篇一律的表格。
